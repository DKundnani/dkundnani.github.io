# Organisation logos

A logo appears next to a role only if a file for it exists here. Nothing is
drawn otherwise, so places without a supplied logo simply show no mark.

Name the file by slug: `<slug>.svg`, `.png`, `.jpg`, or `.webp`.

Slugs: `unm`, `turing`, `gatech`, `mdanderson`, `anshlabs`, `uhcl`, `usha`,
`raheja`, `tsec`, `combinatics`.

Logos are sized to a common tile height (34px in the timeline, 40px in the hero
strip) with width derived from the file's own aspect ratio, so wordmarks and
square marks both sit correctly.

If a logo carries its own background (white artwork on a solid block, for
example), add its slug to `BLEED` in the generator so it sits flush in the tile
instead of being padded on white.
