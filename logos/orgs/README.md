# Organisation logos

Drop a real logo here as `<slug>.svg`, `.png`, `.jpg`, or `.webp` and the next
build uses it in place of the monogram badge. No code change needed.

Slugs: `unm`, `turing`, `gatech`, `mdanderson`, `anshlabs`, `uhcl`, `usha`,
`raheja`, `tsec`, `combinatics`.

Square images work best; they are rendered at 34px. Prefer SVG, or PNG with a
transparent background.
