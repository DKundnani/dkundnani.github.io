# Unused logo variants

Kept in the repository so the site never depends on anything outside it.
Nothing here is referenced by any page.

| File | What it is |
|---|---|
| `gatech-yellowjackets.svg` | Interlocking GT athletics mark, navy and gold. Reads more clearly at small sizes than the seal. |
| `gatech-seal.webp` | Raster of the academic seal. The site uses the SVG version (`../gatech.svg`). |
| `mdanderson-stacked.png` | "The University of Texas / MD Anderson / Cancer Center" stacked lockup. The site uses the wider "Cancer / UT MD Anderson" version (`../mdanderson.webp`). |

To swap one in, copy it over the active file one level up, keeping the slug
name, then rebuild. Widths are derived from each file's aspect ratio, so a
different shape needs no code change.
